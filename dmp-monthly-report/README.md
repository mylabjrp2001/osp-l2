# DMP Monthly Report (BKK) — Web

แปลงรายงาน Power BI "DMP Advance Solution Network (BKK) — Monthly Report" ให้เป็นเว็บ
ที่กรองช่วงวัน / โซน / ทีม / Priority ได้

## โครงสร้าง

```
dmp-monthly-report/
├── etl/
│   └── build_data.py        # Excel → public/data.json
├── public/
│   └── data.json            # generated by ETL (~11.5 MB)
└── src/
    ├── main.jsx · App.jsx · filters.jsx · data.js
    ├── theme.js · utils.js
    ├── components/  PageHeader · FilterBar · ChartCard
    └── pages/       Page02 … Page22 (21 หน้า ตรงกับ PDF)
```

## เริ่มใช้

```bash
cd dmp-monthly-report
npm install          # ครั้งแรกเท่านั้น
npm run etl          # (วิธีเก่า) อ่าน Excel จาก "Excel Data/" → public/data.json
npm run dev          # เปิดที่ http://localhost:5173
npm run build        # production bundle ใน dist/
```

ต้องมี Python 3.10+ และ `pip install openpyxl` สำหรับ ETL

## Backend (upload Excel ผ่านเว็บ)

มี FastAPI backend ใน `server/` สำหรับรับอัพโหลดไฟล์ Excel โดยไม่ต้อง SSH:

```bash
# ติดตั้ง (ครั้งแรก)
python3 -m venv server/.venv
source server/.venv/bin/activate              # Windows: server\.venv\Scripts\activate
pip install -r server/requirements.txt

# รัน
python -m uvicorn server.app:app --host 0.0.0.0 --port 8000
```

จากนั้นรัน Vite dev server คู่กัน (`npm run dev`) — Vite จะ proxy `/api/*` และ
`/data.json` ไปที่ `http://localhost:8000` อัตโนมัติ ใช้ปุ่ม **📥 Upload Excel**
มุมขวาบนเพื่ออัพไฟล์ใหม่ได้เลย

หรือรันทั้งสองพร้อมกันด้วยคำสั่งเดียว (ต้อง setup venv ตามด้านบนก่อน):

```bash
npm run dev:all      # รัน vite + uvicorn คู่กัน (Ctrl+C ปิดทั้งคู่)
```

เข้าใช้งานที่ `https://l2.workproth.com` (Cloudflare Tunnel → `localhost:8000`)

### Deploy บน Windows VPS (ของเดิม — เลิกใช้แล้ว)

1. ติดตั้ง Node.js + Python 3.10+
2. `npm install && npm run build` → ได้ `dist/`
3. ดับเบิลคลิก `server\run.bat` (สร้าง venv ครั้งแรก + รัน uvicorn)
4. เปิด port 8000 ที่ Windows Firewall → เข้าใช้งานได้ที่ `http://<vps-ip>:8000`
5. (เสริม) ใช้ **NSSM** ทำให้ uvicorn รันเป็น Windows Service auto-start

ข้อมูลที่ upload และ `data.json` ที่ build แล้วจะเก็บไว้ที่ `server/storage/`
(เปลี่ยนได้ด้วย env `DMP_STORAGE=<path>`)

### Endpoints

| Method | Path | คำอธิบาย |
|---|---|---|
| GET | `/api/status` | รายการไฟล์ที่อัพโหลด + meta ของ data.json |
| POST | `/api/upload` | multipart upload — ชื่อไฟล์ต้อง `Data Job done <YEAR>.xlsx\|.xlsm` |
| DELETE | `/api/files/{name}` | ลบไฟล์ปีนั้น แล้ว rebuild data.json |
| GET | `/data.json` | dataset ที่ frontend ดึง (no-cache) |

## ตัวกรอง (สามารถปรับได้ในทุกหน้า)

- **ช่วงวันที่** — date picker เริ่ม/สิ้นสุด (อิง REPORT_DATE)
- **Quick presets** — มี.ค./ก.พ./ม.ค. 26 · Q1 · 6 เดือนล่าสุด · ทั้งหมด
- **โซน** — Latkrabang / Pathumthani
- **ทีม** — A / B / C ของแต่ละโซน
- **Priority** — Critical / Major / Minor / None

## หมายเหตุเรื่องตัวเลข

- การจัดกลุ่มเดือน ใช้ **REPORT_DATE** (เพื่อให้ตรงกับ Power BI report ที่บันทึก

- ตัวเลข SLA% บางหน้าอาจคลาดเคลื่อนจาก PDF เดิม 1–2% จากการนับ blank rows
  ปรับ logic ใน `src/pages/Page22_KPISla.jsx` `teamSla()` ได้
